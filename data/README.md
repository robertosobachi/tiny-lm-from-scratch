# Data

The `.txt` files in this folder are gitignored. Download them yourself.

## names.txt (steps 1 to 4)

About 32,000 names, one per line, lowercase.

Source: Andrej Karpathy's makemore repo, https://github.com/karpathy/makemore,
file `names.txt` at the repo root. Save it as `data/names.txt`.

## input.txt (step 5)

Tiny Shakespeare: about 1 MB of Shakespeare's plays concatenated into one file.

Source: Andrej Karpathy's char-rnn repo, https://github.com/karpathy/char-rnn,
file `data/tinyshakespeare/input.txt`. Save it as `data/input.txt`.
